## 1. Загальне

Двомовний сайт музичного лейблу ENKO. Версії **EN / UA** — майже ідентичні з двома винятками (див. §3).

Адаптивність — обов'язкова. Фокус на десктоп. Mobile — повноцінна. Tablet — без окремого breakpoint'а.

Бекенд — мінімальний: маршрутизація форми + (опційно) проста адмінка для редагованого контенту.

---

## 2. Структура сайту

Сайт має **4 сторінки** + 1 зовнішній редирект:

| # | Сторінка | URL | Тип |
|---|---|---|---|
| 1 | ENKO (Home) | `/` | Внутрішня |
| 2 | Publishing | `/publishing` | Внутрішня |
| – | Marketing ↗ | `LIRA_URL` | **Зовнішнє посилання** (нова вкладка) |
| 3 | For Business | `/for-business` | Внутрішня |
| 4 | Get in Touch | `/contact` | Внутрішня |

**Marketing** — це **не окрема сторінка**, а пункт меню, який відкриває сайт партнерської компанії LIRA в **новій вкладці**. Поточна вкладка ENKO залишається відкритою. У меню — візуальна позначка (стрілка `↗`), що це зовнішній редирект.

> ⚠️ Сайт LIRA ще не опубліковано (в розробці). Функціонал редиректу **закладається на старті**, URL підставимо пізніше. Розробнику: винести URL у конфіг (одну константу), щоб замінити одним рядком без перебудови.

## 3. Двомовність (EN / UA)

Перемикач EN / UA — у хедері. Версії майже ідентичні, з винятками:

## 9. Технічні вимоги

### 9.1. Frontend
- Чистий HTML/CSS/JS або фреймворк за вибором розробника (поточний прототип — vanilla JS, легко мігрується).
- Перемикач EN / UA — на frontend (контент з JSON / i18n-файлів).
- Анімації / переходи — за дизайном (буде уточнено після макетів).
- Lazy loading зображень (особливо в каруселях артистів і testimonials).

### 9.2. Backend (мінімальний MVP)
- **Маршрутизація форми контактів** → email per department (див. §7.3).
- **Опційно (MVP+1) — проста адмін-панель** для редагованого контенту:
  - Стрічка мерчу (посилання + назви)
  - FAQ (EN / UA окремо)
  - Список артистів каруселі (фото, текст, посилання)
  - Список testimonials
  - Press-блок (якщо обираємо варіант з ручним керуванням — див. §4.7)

> ⚠️ **Питання до команди розробки:** як ви рекомендуєте реалізувати адмінку?
> - Headless CMS (Strapi / Sanity / Directus)?
> - Кастомна адмінка на базі того ж стека?
> - Просто оновлюваний JSON у репо (для MVP)?
>
> Замовнику важливо, щоб **редагування FAQ, мерчу, тестимоніалів** було можливим без участі розробника. Чекаємо рекомендацію + вплив на естімейт.

### 9.3. Інтеграції
- **Instagram embed / Graph API** — UA-версія Home page (§4.8).
- **SMTP / mail provider** — для маршрутизації форми (§7.3).
- (Можливо) **Spotify / YouTube embed** — для треків і артистів.

### 9.4. Хостинг / Домен
- ⚠️ **Відкрите питання.** Домен `enkomusic.com` (або інший) — деталі поки не фіналізовані.
- Чекаємо рішення замовника. Розробник може запропонувати варіанти (Vercel / Netlify / VPS).

### 9.5. SEO
- Метатеги, OG, Schema.org (Organization, MusicGroup для артистів).
- `hreflang` для EN / UA.
- Sitemap, robots.txt.
- ⚠️ Окремо: вплив відсутності IG-блоку в EN-версії — чекаємо коментар від SEO-команди розробника (див. §3).

## 10. Робочий процес

### 10.1. Поетапна передача
Як тільки фіналізована **окрема сторінка** з дизайном — передається розробнику. **Не чекаємо** на дизайн усіх 4 сторінок.

### 10.2. Копірайт
Дизайнер працює одночасно з копірайтером. Якщо тексту немає на момент макету — placeholder'и.

### 10.3. Дедлайни (orientовно)
- **Кінець тижня:** замовник передає фіналізовану структуру (макет дизайнера) розробнику.
- **+1–2 дні:** розробник готує пак уточнюючих питань.
- **Дзвінок:** замовник + дизайнер + копірайтер + розробник.
- **Estimate:** після уточнень.
- **Старт розробки:** після підпису.
- **Цільовий релізний дедлайн (оптимістичний):** ~2 місяці від старту.

### 10.4. Комунікація
- Telegram-чат (буде створено).
- Тегати Юлію / Анну вільно.
- Дзвінки в робочі години.

## 12. Що НЕ входить у MVP

- **Окремий лендінг Marketing** (замість — редирект на LIRA).
- **Адмін-панель управління мерчем** (тільки посилання на зовнішні магазини).
- **Tablet-специфічний дизайн** (тільки масштабування).
- **Венчурні інвестиції як окрема пропозиція** (об'єднано з "інвестицій в артистів").
- **Платний доступ до повних статей у Press-блоці** — не реалізуємо, лише посилання / цитати (§4.7).
- **Окремий блог / новинна стрічка ENKO.**
